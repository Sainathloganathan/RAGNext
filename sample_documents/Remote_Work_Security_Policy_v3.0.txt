INFORMATION SECURITY MANUAL — VERSION 3.0
EFFECTIVE DATE: JANUARY 1, 2025
EXPIRATION DATE: ACTIVE / INDEFINITE
STATUS: ACTIVE

================================================================================
SECTION 1: REMOTE NETWORK ACCESS
================================================================================
1.1 All remote access requires Zero Trust Network Access (ZTNA) with strict micro-segmentation and continuous posture assessment.
1.2 Maximum idle session timeout is 30 minutes. Re-authentication is enforced at every connection resumption.

================================================================================
SECTION 2: PASSWORD AND AUTHENTICATION STANDARDS
================================================================================
2.1 Traditional passwords are deprecated in favor of FIDO2 WebAuthn hardware security keys (YubiKey 5 Series).
2.2 For fallback systems where passphrases are required, the minimum length is 16 characters. Periodic rotation is eliminated in accordance with NIST SP 800-63B guidelines unless a breach is suspected.
2.3 SMS-based Two-Factor Authentication is strictly banned due to SIM-swapping and telecommunications interception vulnerabilities. Only FIDO2 hardware keys or phishing-resistant push verification are allowed.

================================================================================
SECTION 3: HARDWARE AND DEVICE MANAGEMENT
================================================================================
3.1 BYOD personal devices are 100% prohibited across all departments without exception.
3.2 Only company-provisioned hardware equipped with CrowdStrike Falcon Endpoint Detection and Response (EDR), hardware TPM 2.0, and remote wipe capabilities may access company assets.

================================================================================
SECTION 4: DATA TRANSFER & ARTIFICIAL INTELLIGENCE USAGE
================================================================================
4.1 USB storage ports remain permanently disabled at the hardware BIOS level.
4.2 Corporate AI Policy: Employees may only use internal, offline-hosted document intelligence systems (such as RAGNext with local Ollama inference). Uploading proprietary company code, internal documentation, or customer PII to public cloud AI tools (e.g., ChatGPT, Claude, Gemini Cloud) is classified as a Critical Severity Security Violation.
